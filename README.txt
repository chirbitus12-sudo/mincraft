موقع تحميل باتشات ماين كرافت — نسخة HTML / CSS / JS
=====================================================

هذه نسخة مستقلة تمامًا من موقعك: لا تحتاج سيرفر ولا قاعدة بيانات ولا أي تثبيت.
فقط افتح index.html في أي متصفح (اضغط عليه مرتين) وسيعمل الموقع فورًا.

الملفات
-------
- index.html            : هيكل صفحة الموقع
- style.css             : كل التنسيقات (الثيم الوردي الفاتح)
- script.js             : منطق الموقع (التخزين، التحميل، لوحة التحكم، الإعلانات)
- minecraft-patch.jpg   : الصورة الافتراضية للباتشات

طريقة الاستخدام
---------------
1) افتح index.html في المتصفح (أو ارفع الملفات الأربعة على أي استضافة ثابتة:
   GitHub Pages / Netlify / Vercel / أي استضافة ملفات HTML).
2) الزائر يضغط "Download Patch" أول مرة → يظهر الإعلان داخل البطاقة.
3) يضغط ثاني مرة → يفتح رابط MediaFire في تبويب جديد.

لوحة التحكم السرية (لك وحدك — الزوار لا يرونها أبدًا)
------------------------------------------------------
تُفتح فقط بإضافة #panel إلى نهاية الرابط، مثال:
    index.html#panel

(الشعار في الأعلى للعرض فقط، والنقر عليه لا يفعل شيئًا.)

من لوحة التحكم تستطيع:
  - إضافة باتش جديد (Add patch)
  - تعديل الباتش (Edit): الاسم، الإصدار، الوصف، رابط MediaFire، كود الإعلان
  - تغيير/إضافة/حذف الصورة لكل باتش (تُضغط تلقائيًا إلى 1280px)
  - فتح رابط MediaFire للتأكد منه (Open link)
  - حذف الباتش (Delete) مع تأكيد

مهم: روابط MediaFire الحالية روابط تجريبية (example) —
ضع روابطك الحقيقية من لوحة التحكم → Edit → MediaFire link.

أين تُحفظ التعديلات؟
--------------------
- التعديلات التي تجريها من لوحة التحكم تُحفظ في متصفحك (localStorage)
  وتظهر مباشرة دون تعديل الكود.
- إذا فتحت الموقع من جهاز/متصفح آخر سيرى الباتشات الافتراضية الموجودة
  في script.js داخل قسم SEED_PATCHES — عدّل هذا القسم لتغيير الافتراضيات
  لكل الزوار (مفيد عند رفع الموقع على استضافة عامة).
- لمسح تعديلات المتصفح والعودة للقيم الافتراضية: امسح بيانات الموقع
  من إعدادات المتصفح (Clear site data) أو من وحدة تحكم المتصفح نفّذ:
      localStorage.removeItem("minecraft_patches_v1")

ملاحظات
-------
